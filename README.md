# Banking-Application-Support-System

**Banking Application Support & Incident Management System**  
*Technology: Microsoft SQL Server, T-SQL*

- Developed a banking support database to track customer complaints, transaction statuses, support tickets, error logs, audit history, and SLA information.
- Created SQL queries, stored procedures, views, and indexes to investigate failed and pending transactions and retrieve ticket details.
- Implemented a status-update procedure with transaction handling and a trigger for automatic ticket-status audit logging.
- Practiced troubleshooting scenarios involving transaction failures, pending payments, account-balance discrepancies, login errors, and critical database errors.
